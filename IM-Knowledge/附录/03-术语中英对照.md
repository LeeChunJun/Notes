## 11. 一句话对照（最容易搞混的）

| 说法 A | ≠ | 说法 B |
|---|---|---|
| 短连接 | ≠ | 短任务（Short Task） |
| 长连接 | ≠ | 信令通道（Signaling Channel） |
| 心跳 cmdid=6 | ≠ | UDP 信令 cmdid=243 |
| 信令保活 | ≠ | 信令校验（IdentifyChecker） |
| seq | ≠ | client_sequence_id（16 位，不在线上） |
| taskid | ≠ | 业务 msg_id（幂等键） |
| 客户端版本号 | ≠ | 协议版本号（开源版无） |
| 腾讯的"内部版" | ≠ | 开源版 Mars |
